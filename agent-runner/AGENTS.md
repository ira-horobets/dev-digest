# agent-runner — `@devdigest/agent-runner`

The CI runner for Export to CI (SPEC-05). It is bundled with esbuild into one
file, `dist/index.js`, which is committed. The server embeds that file and the
export copies it into a team's repo as `.devdigest/runner/index.js`, where the
generated GitHub Actions workflow runs it with `node`. Flow, posting fallback
and bundle details: `README.md`.

## Commands (npm)

```sh
cd ../reviewer-core && npm ci   # first time: the bundle consumes reviewer-core by path alias
npm ci
npm run typecheck
npm run lint
npm test            # includes the stale-bundle test (test/bundle.test.ts)
npm run build       # rewrites dist/index.js
```

`verify.sh`, `insight.sh` and `route.sh` do not cover this package: run the
checks above explicitly.

## Layout

- `src/env.ts` · `manifest.ts` · `github.ts` · `review.ts` · `result.ts` · `main.ts` · `index.ts` (calls `main`).
- `test/` — vitest, with `test/helpers/fixture.ts`.
- `build.mjs` — esbuild config, banner `devdigest-ci/v1`, path aliases.
- `dist/index.js` — the committed bundle.

## Conventions

- Never log env values. Never send an `APPROVE` review.
- Import only `reviewer-core`, `@devdigest/shared` and `server/src/adapters/git/diff-parser.ts` (plan D6).
- After changing `src/`, `reviewer-core/src`, `server/src/vendor/shared` or the diff parser, run `npm run build` and commit `dist/index.js`; the stale-bundle test fails otherwise.
- The artifact shape is `CiResultArtifact`; change it in the shared contract first.

## Do not touch by hand

- `dist/index.js` (generated by `npm run build`), `package-lock.json`.
